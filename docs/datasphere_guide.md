В общем, нужно создать где-то в папке проекта конфиг для джобы.
Запустить джобу можно с помощью команды
datasphere project job execute -p {project_id} -c count_job_config.yaml
Так же в скрипте, который вы запускаете, код должен быть обёрнут в if name == "main".
Все библиотеки подтянутся из вашего окружения и установятся на ВМ (для opencv нужно ставить headless версию)
В самом конфиге всё просто:
cmd: - указываете команду, которую нужно исполнить
s3-mounts:
Здесь подключается s3 хранилище по пути - "/job/s3/{project_id}/"
inputs - файлы, которые передадутся на ВМ
outputs - скачаются с ВМ после выполнения.
Веса моделей во время обучения лучше сохранять в s3 хранилище, чтобы не потерять результат при остановке джобы.
Вот документация: https://yandex.cloud/ru/docs/datasphere/concepts/jobs/
